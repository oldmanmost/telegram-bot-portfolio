# 📝 Бот для сбора заявок (FSM)

Демонстрационный бот, который пошагово собирает данные от клиента с помощью машины состояний (FSM). Идеально подходит для записи на услуги, консультации или пробные занятия.

## 🎯 Возможности
- Пошаговый опрос клиента (Имя → Класс → Цель → Телефон)
- Использование Reply-клавиатур с кнопкой "Отправить контакт" для быстрого получения номера
- Мгновенная отправка структурированной заявки администратору в Telegram
- Автоматическая очистка состояния (state.clear) после завершения

## 🚀 Как запустить
1. Установите зависимости: `pip install aiogram`
2. Откройте `bot.py` и замените `YOUR_TOKEN_HERE` на токен от @BotFather.
3. Замените `ADMIN_ID` на ваш цифровой ID.
4. Запустите: `python bot.py`
