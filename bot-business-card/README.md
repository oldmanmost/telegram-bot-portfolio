# 🚗 Бот-визитка для автосервиса "TurboFix"

Демонстрационный бот с интерактивным меню, разделами услуг и мгновенным уведомлением администратора при попытке записи.

## 🎯 Возможности
- Главное меню с inline-кнопками
- Разделы: Услуги, Контакты, Запись
- Уведомление администратору (по ID) при нажатии на "Записаться"
- Кнопки быстрого звонка (`tel:`)
- Полностью на **Aiogram 3.x** (современный асинхронный фреймворк)

## 🚀 Как запустить
1. Установите зависимости: `pip install aiogram`
2. Откройте `bot.py` и замените `YOUR_TOKEN_HERE` на токен от @BotFather.
3. Замените `ADMIN_ID` на ваш цифровой ID (можно узнать через бота @userinfobot).
4. Запустите: `python bot.py`
