# 🤖 Telegram Bot Portfolio

Коллекция готовых решений и шаблонов Telegram-ботов для автоматизации бизнеса и сбора заявок. Все проекты написаны на Python (Aiogram 3.x), готовы к запуску и легко адаптируются под любые ниши.

## 📂 Проекты в этом репозитории

### 1. [Бот-визитка](./bot-business-card)
Интерактивное меню, разделы услуг, цен и контактов, кнопка связи с менеджером. Идеально для салонов красоты, автосервисов, частных мастеров.
- **Технологии:** Python, Aiogram 3.x, Inline-клавиатуры.
- **Время внедрения:** ~1 день.

### 2. [Бот для сбора заявок](./bot-lead-collector)
Пошаговый опрос клиента (FSM), сбор имени, телефона и деталей заказа, мгновенное уведомление менеджера.
- **Технологии:** Python, Aiogram 3.x, FSM (Машина состояний), Reply-клавиатуры.
- **Время внедрения:** ~1 день.

### 3. [Бот-автоответчик (FAQ)](./bot-faq-autoreply)
Умный поиск ответов по ключевым словам, разгрузка менеджера, эскалация сложных вопросов человеку.
- **Технологии:** Python, Aiogram 3.x, Логика поиска по ключевым словам.
- **Время внедрения:** ~1 день.
