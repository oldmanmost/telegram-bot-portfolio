# ❓ Умный бот-автоответчик (FAQ)

Демонстрационный бот, который автоматически отвечает на частые вопросы клиентов, используя поиск по ключевым словам. Если ответ не найден, бот эскалирует вопрос живому менеджеру.

## 🎯 Возможности
- База знаний с умным поиском по ключевым словам (нечёткое совпадение)
- Интерактивное меню с готовыми вопросами (Inline-кнопки)
- Автоматическая пересылка сложных вопросов администратору
- Легкое расширение базы знаний (просто добавьте новый словарь в список `FAQ`)

## 🚀 Как запустить
1. Установите зависимости: `pip install aiogram`
2. Откройте `bot.py` и замените `YOUR_TOKEN_HERE` на токен от @BotFather.
3. Замените `ADMIN_ID` на ваш цифровой ID.
4. Запустите: `python bot.py`
